# 모바일 조작·범위 표시·전투 효과음 업데이트

## 모바일 조작

- 모바일 접속을 자동 감지합니다. 왼쪽은 항상 보이는 이동 패드, 오른쪽은 큰 공격 버튼과 Q/W/E/궁극기 원형 버튼입니다.
- 오른쪽에 영웅·미니언·건물 공격, 상점, 귀환, 물약, 시점 복귀 버튼을 배치했습니다.
- 이동 중 다른 손가락으로 스킬을 끌어 조준하고, 손을 떼면 시전합니다. 상단 취소 영역으로 끌면 시전하지 않습니다.
- 모바일은 가로 화면으로 플레이합니다. 세로로 접속하면 기기를 가로로 돌려 달라는 안내가 나타납니다. 좌우 반전과 버튼 크기 설정을 지원하며, 작은 화면에서는 버튼이 겹치지 않도록 최대 크기를 제한합니다.

## 범위 표시

Tripo로 생성한 크리스털 별과 화살촉을 청백색 테두리·잔광·룬 문양에 결합했습니다. 실제 스킬의 원형 반경, 직선 폭·거리, 부채꼴 각도를 사용합니다. 최대 사거리 원은 약하게, 직접 조준하는 영역은 더 밝게 표시합니다. 지형 높이를 따라 그리며 같은 메시와 장식을 재사용합니다.

모델 생성은 승인된 2회만 진행했습니다. 텍스트 기반 모델 생성 결과에 게임 내 발광 재질과 움직임을 적용했으며, 원본 이미지 전체를 3D로 변환한 결과는 아닙니다.

## 캐릭터별 효과음

Runway로 12명 각각의 기본 공격·피격·Q·W·E·R 효과음을 제작했습니다. 총 **72개**, MP3 합계 **1,688,256바이트**입니다. 캐릭터의 무기와 스킬 성격을 프롬프트에 반영했으며, 기존 게임의 음원을 추출하지 않았습니다.

**Runway 사용 132크레딧**: 기본 공격 12×1, 피격 12×1, 일반 스킬 36×2, 궁극기 12×3. 계정 잔액 665→**533**을 확인했습니다. 실패·재생성 없음. 각 음원의 작업 ID와 파일은 `public/audio/combat/manifest.json`, 제작 프롬프트는 `tools/runway-combat-assets.json`에 기록했습니다.

선택된 캐릭터의 효과음만 경기 시작 시 미리 읽습니다. 앞뒤 무음과 음량 편차를 보정하고, 카메라에서의 거리·방향에 맞춰 재생합니다. 동시 재생은 18개로 제한하며 궁극기를 우선합니다. 궁극기가 나올 때 배경음이 잠깐 낮아지고, 기존 음량 설정과 음소거를 따릅니다. 음원을 읽지 못하면 기존 합성음을 사용할 수 있습니다.
