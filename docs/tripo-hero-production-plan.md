# 캐릭터 장비·전투 이펙트 제작 계획

상태: 전체 27종 승인 후 생성·게임 연결 완료. 실제 사용 1,000크레딧, 잔액 1,075. 작업별 기록은 `hero-asset-generation-ledger.md`를 참고합니다.

12명 캐릭터의 대표 장비 13종, 모듈형 방어구·보조 장비 6종, 전투 이펙트 형상 8종을 제작합니다. 기존 캐릭터의 얼굴과 개성을 유지하고, 장비별 크기·손잡이·장착 위치를 실제 캐릭터에 맞춥니다.

## 입력과 제작 방식

- 입력: `tools/tripo-hero-assets.json`에 저장된 공통 스타일 및 모델별 영문 프롬프트. 은빛/흑철·상아색·금색 테두리와 캐릭터별 마력 색상을 사용한 독창적인 판타지 디자인입니다.
- 모델: CLI 별칭 `tripo-p1`, 실제 모델 값 `P1-20260311`. 삼각형 예산에 따라 CLI가 자동 선택했습니다.
- 각 행은 독립적인 API 호출 1회입니다. 순서대로 `POST /v3/generation/text-to-model`을 사용합니다. 후속 유료 변환·리깅·리타게팅은 없습니다.
- 1~19: `texture=true`, `pbr=true`, 기본 텍스처 품질. 20~27: `texture=false`, `pbr=false`; 게임에서 발광·투명도·색상·잔상·움직임을 적용합니다.
- 실행할 정확한 인자와 오프라인 검증 결과: `dev/tripo-hero-plan.json`. 모든 호출은 `--dry-run --json`으로 검증합니다.

## 저장 위치와 게임 적용

- 원본: `_art/tripo-heroes/tripo-out/pang-hero-<id>-<작업ID앞8자리>/model.glb`, `preview.png`, `task.json`.
- 검토·최적화 후 게임 파일: `public/models/heroes/<id>.glb`, 원본·비용·크기 출처를 담은 manifest.
- 미리보기: `public/art/hero-assets/<id>.webp`.
- 손목 원점이 아닌 손바닥의 실제 잡는 위치에 손잡이를 고정하고 손가락 자세를 조정합니다. 방패판은 손과 팔 앞에 두고 후면 손잡이를 연결합니다.
- 방어구는 몸 표면을 측정해 여유 간격을 주고, 어깨·팔처럼 움직이는 부분은 관절별로 분리합니다. 대기·이동·공격·시전 자세에서 확인합니다.
- 이름은 11 → 13 크기, 굵기는 600 → 700으로 조정합니다. 체력바 및 상태 표시와 간격도 확인합니다.
- 8종 이펙트 형상에 캐릭터별 색상, 크기, 회전·확산·잔상을 결합합니다. 기본 공격·일반 스킬·궁극기의 강도를 구분하고 기존 사전 경고 및 적중 범위를 유지합니다.
- PC·모바일에서 12명 장비, 기본 공격과 Q/W/E/R, 이펙트 정리 및 게임 진입을 검증합니다.
