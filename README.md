# 리그 오브 팽재현 (가제)

양식화된 3D 판타지 스타일의 **4대4 AOS** 게임입니다. 첫 실행 버전은 **플레이어 1명 + AI 7명**으로 캐릭터 선택부터 결과 화면까지 한 경기를 끝까지 플레이할 수 있습니다. PC(키보드·마우스)와 모바일 브라우저(가로 화면 터치)를 지원합니다.

**▶ 바로 플레이: https://shangho90-sudo.github.io/league-of-pang/** (PC·모바일 브라우저, 모바일은 가로 화면)

> 시작 화면의 **온라인 대전**에서 로그인 없이 1대1~4대4 경기에 참여할 수 있습니다. 경기와 대기실은 Railway 싱가포르 서버가 처리하며, 기존 4대4 AI 모드도 유지합니다. 운영·배포 방법은 [온라인 서버 안내](docs/online-server.md)를 보세요.

## 실행 방법

빌드 결과물은 정적 파일이므로 아무 웹 서버로나 실행할 수 있습니다. (`file://`로 직접 열면 브라우저 보안 정책 때문에 모델 로딩이 막힙니다.)

```bash
# 배포 폴더에서
npx serve .           # 또는: python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 (또는 표시된 주소) 접속
```

모바일 기기에서는 같은 네트워크에서 PC의 주소(예: `http://192.168.0.10:8080`)로 접속한 뒤 가로로 돌려서 플레이합니다.

### 소스에서 빌드

```bash
npm install
npx esbuild src/main.js --bundle --format=esm --minify --outfile=dist/main.js
```

## 조작

**PC** — 우클릭 이동/공격, A+좌클릭 공격 이동, S 정지, B 귀환, Q/W/E/R 스킬(즉시 시전 또는 범위 확인 후 시전), Ctrl+Q/W/E/R 스킬 레벨업, 스페이스 내 캐릭터로 카메라, Y 카메라 고정 전환, 휠 확대·축소, 화면 가장자리 카메라 이동, Tab 전적, P 상점, 1~6 아이템, Esc 설정.

**터치(가로)** — 왼쪽 아래 조이스틱 이동. 공격 버튼을 누르고 있으면 반복 공격(적 포탑 안으로 무리하게 추격하지 않음). 영웅/미니언/건물 버튼으로 대상 종류를 지정해 공격합니다. 스킬 버튼을 드래그해 조준하고 손을 떼면 시전, 취소 영역으로 끌면 취소됩니다. 아군 대상 스킬은 초상화로 대상을 고르고, 빠르게 터치하면 자신에게 사용합니다. 적이나 적 초상화를 터치하면 대상을 고정합니다. 빈 화면 드래그와 미니맵으로 카메라를 움직이고, 카메라 버튼으로 복귀합니다. 설정에서 좌우 반전, 조이스틱 크기·위치·감도, 버튼 크기·투명도, 대상 우선순위, 자동 조준 보조를 바꿀 수 있습니다.

## 구조

```
src/
  map/layout.js      전장 정의(공격로·정글·강·덤불·포탑·기지) — 지형·내비·AI·미니맵 공용
  map/grid.js        보행/높이/덤불 그리드, A* 경로 탐색
  sim/sim.js         게임 규칙(이동·전투·상태이상·시야·웨이브·성장·승패) — 렌더링과 분리
  sim/skills.js      스킬 48개 + 패시브 12개 (판정 도형 = 텔레그래프 도형)
  sim/ai.js          챔피언 AI (팀 시야만 사용)
  data/champions.js  캐릭터 수치·스킬 데이터 (밸런스 조정 지점)
  data/items.js      아이템·AI 빌드
  render/*           지형·식생·구조물·캐릭터 리그·장비
  client/*           월드 렌더, 이펙트, HUD, PC/터치 입력, 오디오, 선택 화면
tools/               모델 최적화, 헤드리스 경기 시뮬레이션, 실제 빌드 검증 스크립트
```

입력은 플랫폼별로 나뉘어 있습니다(`client/input.js`의 `PCInput` / `TouchInput`). 이동·전투·스킬·피해 판정은 모두 같은 `Sim` 명령 API(`cmdMove`, `cmdJoy`, `cmdAttack`, `cmdCast` …)를 거칩니다. AI도 같은 API를 씁니다. 온라인 모드는 `src/client/online.js`에서 명령을 전송하고, `server/match-worker.js`에서 같은 시뮬레이션을 실행합니다.

구현 현황과 검증 결과는 `STATUS.md`, 외부 자산 출처는 `ASSETS.md`를 보세요.
